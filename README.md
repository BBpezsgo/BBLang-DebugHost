# Debugger host for my [programing language](https://github.com/BBpezsgo/BBLang)

[![.Net 11.0](https://img.shields.io/badge/.NET-11.0-5C2D91?style=flat-square)](#)

## Features:
- breakpoints
- variables
- expression evaluation
- bytecode inspection (it's called "disassembly" in DAP)
- step-in, -forward, -up
- memory inspection
- compiled scripts  (it's called "loaded sources" in DAP)
